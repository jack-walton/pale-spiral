Complete the following steps to search for events.

<Steps>
1. **Start Your Search**

   From the **Search** screen, select the search bar at the top of the screen. Enter an event name, artist, or venue. Results appear as you type.

   <Image src={resultsImg} alt="The Search screen showing search results for Taylor Swift" />

   You can also browse events without searching. Use the **Discover Events** filters — **Today**, **Tomorrow**, **This Weekend**, or **Recently Announced** — to narrow events by date. Select a genre from **Explore Event Genres** to browse by category. See [Navigate the App](/venu/navigate-the-app/) for more information about the Search screen.

2. **Select an Event**

   Select an event from the results or browse list to open its detail page. The event detail page displays the event name, date, time, venue, and available ticket options.

   <Image src={eventDetailImg} alt="The event detail page for Taylor Swift | The Eras Tour showing date, time, venue, and ticket options" />

   Two ticket types are available:

   - **Tickets** — standard admission at face value price
   - **VENU Official Resale** — verified fan-to-fan resale tickets, which may exceed face value

3. **Buy Tickets**

   Select **Buy Now** to begin the ticket purchase. See [Buy Tickets](/venu/buy-tickets/) for more information.
</Steps>
