VENU is an app prototype I designed in Figma. The app lets you search for events, purchase tickets, and sell them later if you cannot attend. You can try the prototype at [gills-crank-13926490.figma.site](https://gills-crank-13926490.figma.site/).

The guide is written in a shorter, task-focused register — deliberately lighter than the enterprise documentation in the Oracle section.
