title: Create an Account

import { Steps } from '@astrojs/starlight/components';

Complete the following steps to create an account.

<Steps>
1. **Access the Registration Screen**

   Select the **Profile** button at the top of the app. See [Navigate the App](/axs/navigate-the-app/) for more information about how to access the **Profile** screen.

   Select **Log In or Sign Up**. If you have a Facebook account or an Apple account, you can use those credentials to create an account. Otherwise, select **Sign Up** to register with your email address.

   ![The Log In or Sign Up screen with options to continue with Facebook, Apple, or email](/images/AXS/create_an_account/create_an_account_step_1.jpg)

2. **Enter Your Information**

   Enter your first name, last name, email address, and a password. Ensure that the password is at least eight characters long and contains the following characters:
   - One uppercase letter
   - One lowercase letter
   - One number

   Select the checkbox to indicate that you understand you might need to show identification to enter a venue.

   ![The account creation form with fields for name, email address, and password](/images/AXS/create_an_account/create_an_account_step_2.jpg)

   Read the **Terms and Conditions** and the **Privacy Policy**. If you agree to the terms, select **Create Account**.

3. **Verify Your Account**

   Access your email inbox and view the email that AXS sent you. Select **Verify Email**. A confirmation message is displayed in your browser. After you have verified your email, in the AXS App, select **Continue**.

   Enter your telephone number. Then, select **Send Code Via Text** to verify your account. Enter the six-digit code sent to your phone.

   ![The phone number entry screen with a Send Code Via Text button](/images/AXS/create_an_account/create_an_account_step_3.jpg)
</Steps>
