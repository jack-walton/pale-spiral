I'm a technical writer based in New York. For the past four years I've worked at Oracle, documenting AI-assisted healthcare products across the full content lifecycle — UX research, UI copy, user guides, and release notes.

This site collects work in a few different forms.

- [Oracle](/oracle/) — user guides and release notes I wrote for Oracle Health Claims, Prior Authorizations, and Payments
- [AXS User Guide](/axs/) — a speculative guide covering account setup, navigation, event search, and ticket purchase
- [Bandcamp](/bandcamp/) — a research paper analyzing Bandcamp's information retrieval system through an Organization of Information lens
- [Prompt Engineering](/ai/) — a structured Claude Code prompt I use to generate change logs from git history, included here as a working artifact
