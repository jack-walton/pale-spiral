This section documents a structured prompt I use with Claude Code. The prompt is functional — it runs against this repository — and is included here as a portfolio artifact.

The [Change Log Generator](/ai/change-log/) analyzes the git commit history of a repository and produces a formatted, customer-facing change log. The [Change Log](/changelog/) page on this site is its output.

The prompt uses `$ARGUMENTS` — a Claude Code placeholder replaced at runtime with whatever input you pass to the command. In this case, it receives the repository's git log, making the prompt reusable across any project without modification.
